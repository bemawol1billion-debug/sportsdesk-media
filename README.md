# sportsdesk-media

스포츠데스크(@sport_news_desk) SNS 게시용 미디어 임시 보관소입니다.

## 용도

- 카드뉴스 이미지(1080×1440)와 숏폼 영상(1080×1920)을 게시 전에 임시로 보관합니다.
- 예약 게시 도구(Zernio)가 이 저장소의 공개 URL에서 파일을 가져가 게시합니다.

## 폴더 구조

- `cards/YYYY-MM-DD/` : 일일 카드뉴스 (01.png ~ 05.png)
- `shorts/YYYY-MM-DD/` : 숏폼 영상 (video.mp4, cover.png)

## 운영 규칙

- 파일은 실제 게시가 끝난 뒤 7일이 지나면 삭제합니다.
- 이 저장소의 콘텐츠는 게시 전 상태일 수 있습니다. 무단 사용을 금합니다.
- 보도 사진, 선수 사진, 경기 영상은 저장하지 않습니다.
