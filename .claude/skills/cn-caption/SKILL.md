# cn-caption

검사 도구가 이 폴더에 있다.

```bash
python -I -X utf8 caption.py 캡션.txt --keywords "손흥민,MLS 플레이오프"
```

피드가 보여 주는 대로 첫 125자를 상자로 찍어 준다. 다른 것보다 그 상자를 먼저 읽는다.
한글 해시태그와 한국어 행동 요청("댓글로 남겨", "저장해 두고" 등)을 센다.

## 카드뉴스 캡션은 늘 첫 줄이 후킹이다

표지가 이미 글자를 다 썼다. 피드에서 표지 아래 보이는 캡션 첫 줄이 다시 후킹을 맡는다.
표지 문구를 그대로 반복하지 말고 같은 말을 다른 각도로.

```
첫 줄     약 125자 보이는 칸. 후킹. 인사·해시태그·이모지로 시작하지 않는다.
          설문형은 🗳 + 표지와 같은 직접 질문.
본문      짧은 문단 2~4개, 문단 사이 빈 줄. 사실 3~4문장. 검색될 말은 문장 안에.
요청      하나. 설문형 끝 문장은 "아래 설문에 투표하고, 그렇게 생각한 이유를 댓글로 남겨주세요 👇"
출처      "출처: 언론사, 언론사" / 사진이면 "표지 사진: 작가 / Unsplash (자료 사진)"
          AI 이미지면 "AI 생성 이미지". 출처 줄은 요청이 아니다.
해시태그  5개 이하, 맨 아래 한 줄.
```

## 해시태그

인스타는 2025년 12월 18일부터 게시물당 해시태그를 5개로 제한했다. 해시태그는 도달을 늘리는
수단이 아니라 주제 이름표다. 선수·팀·대회·제도 이름처럼 구체적인 것만 쓴다(#손흥민 #LAFC #MLS).
#fyp, #viral, #explore, #인기 같은 아무것도 설명하지 않는 태그는 뺀다.

## 검색어가 해시태그보다 중요하다

인스타 검색은 캡션 본문을 읽는다. 사람들이 칠 말(선수 이름 + 상황, 제도 이름)을 2~3개 정하고
본문 문장 안에 자연스럽게 넣는다. 그 말을 `--keywords`로 검사기에 넘긴다.

## 규칙

- **링크 금지.** 캡션 링크는 눌리지 않는다. 신청 주소가 필요하면 "프로필 링크"나 "○○ 누리집"처럼 적는다.
- **요청은 하나.** 둘이면 없는 것과 같다. 검사기가 센다. "저장해 두고 + 응원 댓글"은 둘이다.
- **이모지는 문장부호처럼.** 100자당 4개를 넘기면 검사기가 경고한다.
- **사실만.** 캡션 본문은 카드 본문과 같은 근거(보도 2곳 이상)를 쓴다. 과장은 첫 줄까지만.
- **대체텍스트**를 함께 쓴다(표지 최소 1장).

## 순서

1. 초안을 쓴다.
2. `/cn-human`으로 다듬는다.
3. `caption.py`에 검색어를 넣어 돌린다. FAIL은 모두 고치고, WARN은 고칠지 말지 이유를 적는다.
4. 복사용 캡션과 영수증을 낸다.

```
캡션 준비됨
첫 줄:     27자, 잘리지 않음
요청:      하나, 응원 댓글
해시태그:  5
검색어:    "손흥민" 1줄, "MLS 플레이오프" 3줄
검사:      READY
```

게시하지 않는다. 일반형은 완성본 확인 뒤 Zernio 예약, 설문형은 사용자가 붙여 넣는다.
