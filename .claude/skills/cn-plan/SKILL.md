# cn-plan

다른 cn- 스킬은 실행하고 이 스킬은 무엇을 실행할지 정한다. 매주 월요일 같은 시간에 한 번.

## 읽을 것

- `content/insights.md`(`/cn-audit` 결과, 우리 계정 근거)
- `content/swipe.md`(`/cn-viral` 결과, 지금 다른 계정에서 먹히는 표지 공식)
- `content/log.md`(최근 2주 주제, 반복 방지)
- `content/queue/`(대기 원고), 이번 주 스포츠 일정·발표·신청 마감

우리 계정 근거가 이 스킬의 일반론보다 우선이다.

## 하루 구성

하루 3개: 일반형 2 + 설문형 1. 슬롯 11:30 · 17:30 · 21:00. 하루 안에서 종목이 겹치지 않는다.
생활정보형이 하루 1개 이상.

## 섞는 법

기준 문서 3장의 주제 유형을 섞는다.

| 유형 | 일주일에 | 하는 일 |
|---|---|---|
| 1 이슈·논란 | 4~6 | 사람들이 이미 말하고 있는 것. 설문형과 잘 맞는다 |
| 2 새 소식 | 4~6 | 막 나온 뉴스, 숫자 하나와 함께 |
| 3 다가오는 정책·일정 | 2~3 | 날짜가 있는 것. 마감 전에 여유 있게 |
| 4 새로 생기거나 없어지는 것 | 2~3 | 제도·규정·시설 |
| 5 일반인 참여·빅 이벤트 | 2~3 | 대회 접수, 대형 대회 일정·예매 |

- 같은 유형, 같은 카드 구성(text→stats→why 등)을 이틀 연속 쓰지 않는다.
- 지난 게시물의 후속·연장선은 내지 않는다.
- 칸마다 **주제가 아니라 각도**를 적는다. "야구"가 아니라 "잠실 철거로 LG·두산이 옮기는 구장".

## 시각에 대해 솔직하게

게시 시각보다 표지가 훨씬 중요하다. 성과가 좋으면 인스타는 며칠이고 계속 보여 주고, 표지가 약하면
좋은 시각에 올려도 묻힌다. 표지가 약한데 시각을 만지고 있으면 그렇다고 말한다.

## 참여 (선택)

다른 스포츠 계정 댓글로 노출을 늘리는 건 사용자가 원할 때만. 초안은 `/ig-comment`로 만들고
직접 달지 않는다.

## 출력

```
11/17 주간

월  11:30 일반 유형2 C1  축구 · ○○ 이적 확정, 이적료 ○○억
    17:30 일반 생활정보 C4 · 스포츠강좌이용권 마감 D-3
    21:00 설문 유형1 C6  야구 · ABS 판정, 오심일까?
화  ...

이번 주 근거: insights 11/16 "C1 표지가 상위 5 중 4개"
```

저장소 `content/plan.md`에 쓴다. 아무것도 예약하지 않는다. 날마다 그날 원고는 05:51 작업에서
최신 소식으로 다시 확인하고 바꿀 수 있다.
