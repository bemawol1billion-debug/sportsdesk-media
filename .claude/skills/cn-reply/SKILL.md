# cn-reply

게시물 아래 댓글창에서 도달이 정해진다. 답글 하나하나가 게시물의 반응이고, 첫 1시간 답글이 가장
크게 작용한다. 하지만 댓글마다 값어치가 달라서, 쓰기 전에 먼저 나눈다.

## 입력

사용자가 붙여 넣은 댓글이나 캡처, 또는 Zernio 댓글 도구(`comments_list_inbox_comments`,
`comments_get_inbox_post_comments`)로 읽어 온 것. 브라우저로 긁어 오지 않는다.

## 먼저 나누기 (개수를 말한다)

| 분류 | 무엇 | 대응 |
|---|---|---|
| **정정** | 사실 오류 지적 | **가장 먼저.** 확인해서 맞으면 인정하고 바로잡는 답 + 사용자에게 카드·캡션 수정 여부 보고 |
| **내용** | 근거·반론·추가 정보 | 가장 긴 답. 맞는 부분부터 인정하고 우리 근거(출처)를 말한다 |
| **질문** | 여럿이 궁금해할 질문 | 그 자리에서 답 + 새 주제 후보로 표시(후속편 금지와 겹치지 않을 때만) |
| **설문 의견** | 한쪽 편 드는 댓글 | 짧게 받아 주되 우리는 편들지 않는다 |
| **응원** | "🔥", "잘 봤어요", 친구 태그 | 좋아요 + 3~8자 |
| **소음** | 광고·도배·비방 | 답하지 않는다. 욕설·비하는 숨기기 제안 |

이 순서로 쓰고, 값이 끝나는 곳에서 멈춘다.

## 답하는 법

- **질문엔 그 자리에서 답한다.** DM으로 보내지 않는다.
- **상대 이름은 처음에 한 번,** 느낌표 없이.
- **상대 길이에 맞춘다.** 네 글자 댓글에 네 줄 답 금지.
- **비판에는** 맞는 부분을 상대 말로 먼저 인정하고, 그다음 근거로 선을 지킨다. 지우지 않고, 방어적이지
  않고, 한 스레드에 두 번 답하지 않는다.
- **비방에는** 답하지 않는다. 답이 곧 그들이 원하는 노출이다. 숨기기 기능을 쓰는 건 지는 게 아니다.
- **팀·선수·팬을 깎아내리는 답, 한쪽 팬을 편드는 답은 쓰지 않는다.**
- **사실 정정은 숨기지 않는다.** 틀렸으면 "맞습니다, ○○로 바로잡습니다"가 계정 신뢰를 지킨다.

## 출력

분류별로, 복사용 답글(`/cn-human` 거친 것)과 함께.

```
답글 · 댓글 37개 · 정정 1, 내용 3, 질문 2, 설문 의견 12, 응원 17, 소음 2

정정
@handle "1라운드 20일 아니고 21일 아닌가요?"
> 보도마다 20일·21일로 엇갈려 있어서 '20일 전후'로 적었어요. 일정 확정되면 고정 댓글로 남길게요.
  → 사용자 확인 필요: 캡션 수정할지

질문 → 새 주제 후보
@handle "정상빈은 이번 시즌 몇 골이에요?"  (좋아요 21)

소음(2) 답하지 않음.
```

**사용자가 확인하기 전에는 아무 답글도 달지 않는다.** 사용자가 붙여 넣거나, 확인한 것만 대신 단다.
