# cn-human

도구 두 개가 이 폴더에 있다. 눈대중으로 하지 말고 돌린다.

```bash
python -I -X utf8 humanize.py 초안.txt -o 정리.txt --report   # 고치고, 바뀐 곳 보이기
python -I -X utf8 detect.py 초안.txt 정리.txt                 # 다섯 가지 점수, 전후 비교
```

## 자동으로 고쳐지는 것

- **보이지 않는 문자:** 폭 없는 공백·결합 문자, 줄바꿈 없는 공백, 바이트 순서 표시 등. 키보드로는
  안 생기고 복사해도 남는다.
- **문장부호:** 긴 줄표(—)→쉼표, 둥근 따옴표→곧은 따옴표, 말줄임 문자(…)→점 세 개, 글머리 기호→하이픈.
- **영어 상투어:** `slop.json` 사전. 영어 위주라 한국어 문장에는 거의 걸리지 않는다.

## 한국어는 손으로 본다 (도구가 못 잡는 것)

| 볼 것 | 예 | 고치는 법 |
|---|---|---|
| 기사체 상투어 | "귀추가 주목된다", "눈길을 끈다", "화제를 모으고 있다", "~라고 할 수 있다", "주목할 만하다" | 사실 하나로 바꾸거나 지운다 |
| 같은 길이 문장만 연속 | "~했다. ~했다. ~했다." | 짧은 문장 하나, 긴 문장 하나를 섞는다 |
| 셋씩 나열 버릇 | "속도, 정확성, 그리고 집중력" | 진짜 중요한 하나나 둘만 |
| 한 단어 질문 줄 | "결과는?" "과연?" | 답을 바로 쓴다 |
| "단순히 A가 아니라 B" | | B만 말한다 |
| 습관성 요청 | "팔로우하고 더 보기", "친구 태그하세요", "좋아요 꾹" | 게시물마다 요청 하나만, 그 게시물에 맞는 것으로 |
| 이모지 글머리표 목록 | ✅ ✅ ✅ | 문장으로 |
| 번역투 | "~에 있어서", "~를 통해", "~하는 것이 가능하다" | 짧은 우리말로 |

고친 뒤 `detect.py`를 다시 돌린다.

## 다섯 가지 점수

`detect.py`가 0~100으로 매긴다(높을수록 사람 글).

| 항목 | 재는 것 |
|---|---|
| BURSTINESS | 문장 길이 변화 |
| SPECIFICITY | 숫자·이름 같은 구체성 |
| SLOP DENSITY | 상투어 빈도(영어 사전 기준) |
| FINGERPRINT | 보이지 않는 문자·긴 줄표·둥근 따옴표 |
| VOICE | 구조적 버릇 |

카드 문구와 캡션은 짧아서 SPECIFICITY·VOICE가 "판단하기 짧음"으로 50점에 묶이기 쉽다. 그때는
FINGERPRINT 100, BURSTINESS를 올리는 데 집중하고 위 한국어 표를 직접 확인했다고 적는다.

## 정직하게

이 점수는 이 PC에서 돌리는 자체 지표다. 외부 AI 판별기 결과를 약속하지 않는다. "AI 티가 안 난다"고
장담하지 않는다.

## 순서

1. `humanize.py --report`
2. 한국어 표를 보고 해당 줄을 손으로 고친다.
3. `detect.py 초안 정리`로 전후를 보인다.
4. 다듬은 문구와 점수를 **함께** 낸다. 점수만 내지 않는다.
