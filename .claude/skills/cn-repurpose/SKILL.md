# cn-repurpose

좋은 긴 자료 하나엔 카드뉴스 2~4개가 들어 있다. 대부분 하나만 뽑고 나머지를 버린다.

## 입력

보도자료, 지자체·협회 공고문, 정책 발표, 대회 요강, 긴 기사. 주소를 주면 읽고, 못 읽으면 붙여
넣기를 부탁한다. 전부 읽고 나서 뽑는다. 이 자료 하나만으로 사실을 확정하지 않는다. 카드에 쓸 사실은
기준 문서대로 보도·공식 발표 2곳 이상으로 다시 확인한다.

## 요약하지 말고 뽑는다

자료 요약은 카드뉴스가 아니다. 혼자 서는 것만 뽑는다.

| 뽑을 것 | 무엇 |
|---|---|
| **쟁점** | 의견이 갈릴 문장 → 설문형 후보 |
| **숫자** | 금액, 기간, 인원, 비율, 기록 → stats 장 |
| **날짜** | 신청 기간, 마감, 시행일, 대회일 → dday 장 |
| **대상·조건** | 누가, 어떻게 신청하나 → 생활정보형 |
| **바뀌는 것** | 전과 후 → compare 장 |
| **그대로 인용할 문장** | 15단어 미만, 1회까지만 |

쓰기 전에 찾은 것을 개수와 함께 나열한다. 네 개 미만이면 자료가 얇은 것이니, 억지로 여러 개 만들지
말고 그렇다고 말한다.

## 게시물로 나누기

- **쟁점** → 설문형.
- **대상·조건·날짜** → 생활정보형(저장할 가치가 있는 정보).
- **숫자·바뀌는 것** → 일반형.

게시물 하나하나가 완전히 혼자 서야 한다. 보는 사람은 원자료를 본 적 없고 앞으로도 안 본다.
"지난 게시물에서 말했듯" 금지(후속편 금지와도 맞물린다). 같은 자료에서 나온 게시물이라도 표지 공식은
서로 다르게(`/cn-carousel` C1~C10). 같은 모양 표지가 이어지면 공장처럼 보인다.

같은 날 세 개 중 둘 이상을 한 자료에서 쓰지 않는다. 날짜가 있는 건 마감 전에 여유 있게 배치한다.

## 출력

```
자료: 2027 스포츠강좌이용권 공고 (지자체 공고문, 4쪽)
찾음: 쟁점 1, 숫자 6, 날짜 3, 대상·조건 4, 바뀌는 것 2

배치
11/9  11:30 생활정보 C4  "신청 시작, 한 달 최대 ○만 원"  → 대상·금액·기간
11/12 21:00 설문    C6  "소득 기준 확대, 찬성? 반대?"
11/20 17:30 생활정보 C4  "마감 D-7, 아직 안 했다면"    → 신청 방법·주의점
```

요청이 오면 하나씩 `/cn-carousel` → `/cn-caption` → `/cn-human` 순으로 만든다. 한꺼번에 다 쓰지
않는다. 다 같은 소리가 된다.
