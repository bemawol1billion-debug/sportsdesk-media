# cn-carousel

카드는 넘기는 동작 자체가 반응이라 머무는 시간이 길다. 그리고 인스타는 반응하지 않은 사람에게
2장부터 다시 보여 주기도 한다. 그래서 **표지와 2장이 각각 혼자 읽혀야 한다.**

기준 문서(`docs/카드뉴스_제작규칙.md`)가 이 스킬보다 우선이다. 규격은 1080×1440(3:4), 3~5장,
렌더러 `templates/cardnews/render_v3.py`.

## 표지: 결과의 80%

표지 = 노랑 키워드(검색어) + 흰 후킹 2줄(줄당 12자 안팎) + 부제 2줄 + 숫자 배지.
과장·단정 표현을 주로 쓴다. 아래 공식 중 하나를 고르고 번호를 원고 JSON(`cover_formula`)과
log.md에 남긴다. 성과 분석(`/cn-audit`)이 이 번호로 무엇이 먹히는지 가린다.

| 번호 | 공식 | 예 |
|---|---|---|
| C1 | 숫자 충격 | "11경기 10승, 이게 말이 돼?" |
| C2 | 단정 | "잠실 시대, 끝났다" |
| C3 | 반전 | "골보다 도움, 손흥민이 달라졌다" |
| C4 | 마감·임박 | "신청 3일 남았다, 놓치면 1년" |
| C5 | 사라짐·새로 생김 | "없어진다? 거의 확정 단계" |
| C6 | 대결 질문(설문형) | "kt냐 삼성이냐, 누가 이길까?" |
| C7 | 돈·혜택 | "운동하면 돈 준다" |
| C8 | 아무도 말 안 한 것 | "다들 모르는 PO 규칙 하나" |
| C9 | 비교 | "같은 7골, 완전히 다른 시즌" |
| C10 | 참여 권유(대회·이벤트) | "일반인도 뛴다, 접수 시작" |

- **결과를 표지·제목에 넣지 않는다(11/9 사용자 지시).** 후킹·부제·배지·각 장 제목은 궁금증만
  만들고, 결과·숫자·결론은 본문에서 밝힌다. 배지는 "?" + 질문 라벨("개막은 언제로?")로 쓴다.
  위 공식 예시 중 결과를 말해 버리는 것(C1·C2 등)은 질문형으로 바꿔 쓴다. 마지막 요약 장만 예외.
- 돌려 말하는 비유("누가 웃을까?") 금지. 설문형은 직접 묻는다.
- 표지가 앞서 나가면 2장에서 실제 단계를 바로 밝힌다. 표지 숫자는 2장에서 확인시킨다.
- 사용자가 타이틀을 주면 맞춤법만 고쳐 그대로 쓴다.
- 그리드 썸네일에서도 읽히는 크기. 글씨는 가장자리 120px 안쪽.

## 장 구성

| 장 | 역할 | 규칙 | 렌더러 타입 |
|---|---|---|---|
| 1 | 표지 | 위 공식 | cover |
| 2 | 판돈(무슨 일) | 왜 중요한지 한 문장으로 시작. 배경 설명으로 시작하지 않는다. 두 번째 표지 | text |
| 3~(N-1) | 한 장에 한 생각 | 제목 3~7어절, 본문 2~3문장. 넘치면 덜어낸다(5장 제한) | stats · compare · why · dday |
| N | 요약 겸 행동 요청 | 핵심 2줄 요약 + 요청 **1개** | closing (설문형은 vote) |

- **장 번호**(2/5)와 **모든 장 하단 @sport_news_desk**는 렌더러가 자동으로 넣는다(11/9). 끝이 보이면
  끝까지 넘기고, 캡처는 계정 이름 없이 퍼지기 때문이다. 하단 왼쪽 출처 줄이 길면 핸들과 겹치는지 렌더 후 확인한다.
- **32px 미만 글씨 금지.** 폰에서 실제 크기의 1/3로 읽힌다.
- **요약 장은 맥락 없이 읽혀야 한다.** 사람들이 캡처해서 보내는 장이고, 보내기(공유)가 가장 강한 신호다.
- **행동 요청은 하나:** 저장 / 댓글(이유·응원) / 친구에게 보내기 / 팔로우 중 하나. 설문형의
  "설문에 투표하고 이유를 댓글로"는 묶인 요청 하나로 본다.
- **본문은 사실만.** 사실마다 보도 2곳 이상, 각 장 하단 출처. 지어내기·가짜 인용·비하 금지.
- **대체텍스트:** 최소 표지 1장. 화면 낭독기와 인스타 검색이 읽는다.

## 출력과 순서

1. 장별 문구를 번호 목록으로 먼저 보인다(10초 안에 읽고 고칠 수 있게).
2. 캡션은 `/cn-caption`(카드뉴스는 늘 첫 줄이 후킹).
3. 표지·장 문구·캡션 모두 `/cn-human`을 거친다.
4. 그다음 렌더하고 표지·주요 장을 직접 열어 확인한다.

```
카드뉴스 · 5장 · 표지 공식 C3
1 표지   손흥민 / 골보다 도움, / PO에선 해결사?   배지 15 시즌 리그 도움
2 무슨 일 최종전 패배, 서부 6위로 PO 직행
3 숫자   7골 15도움 / 시즌 첫 10경기 도움 7개 / 4경기 무공격포인트
4 관전   3전 2선승, 한 번 지면 벼랑
5 요약   도우미 손흥민, PO에선 해결사로 / 요청: 응원 댓글
대체텍스트(표지): 야간 경기장에서 공을 모는 축구 선수 사진 위에 '손흥민, 골보다 도움' 제목
```

게시는 하지 않는다. 완성본 확인 뒤 예약은 기준 문서 5장 절차를 따른다.
