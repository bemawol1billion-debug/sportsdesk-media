# 예약 원고 대기열

매일 아침 카드뉴스 작업은 이 폴더를 먼저 확인한다.
- 파일명 `YYYY-MM-DD_<주제>.json`: 해당 날짜에 3개 중 하나로 반드시 포함한다.
- 포함 전에 원고의 사실(특히 날짜·D-day·발표 여부)을 다시 검색해 최신으로 고친다. D-day는 게시일 기준으로 다시 계산한다.
- 게시(예약)되면 파일을 `content/YYYY-MM-DD/`로 옮기고 log.md에 기록한다.
