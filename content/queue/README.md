# 예약 원고 대기열

매일 아침 카드뉴스 작업은 이 폴더를 먼저 확인한다.
- 파일명 `YYYY-MM-DD_<주제>.json`: 해당 날짜에 3개 중 하나로 반드시 포함한다.
- 포함 전에 원고의 사실(특히 날짜·D-day·발표 여부)을 다시 검색해 최신으로 고친다. D-day는 게시일 기준으로 다시 계산한다.
- 게시(예약)되면 파일을 `content/YYYY-MM-DD/`로 옮기고 log.md에 기록한다.

## 대기 중
- 2026-11-07_sports_voucher.json — 생활정보: 2027 스포츠강좌이용권 신청(11/9~27). 신청 시작 전 게시. 국민체육진흥공단 전국 공고로 숫자 재확인
- 2026-11-08_gym_tax_deduction.json — 생활정보: 헬스장·수영장 이용료 소득공제(연말정산 대비). 근거가 2025년 시행 당시 자료 → 2026년 기준 변경 여부 재확인

## 처리 완료
- 2026-11-04_ski_dday.json → content/2026-11-04/1104_A_ski_dday.json (11/4 11:30 예약). 시리즈 후속: 비발디·웰리힐리·엘리시안·곤지암·지산 개장일 발표 시 업데이트편.
